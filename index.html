How the packs work

  1. 01

    Stream

    A .arcp container arrives over HTTPS with a live byte counter. Cancel any time.

  2. 02

    Verify

    The browser hashes the payload and compares it with the catalog's SHA-256 before running a single line.

  3. 03

    Keep

    Bytes go into IndexedDB. Next launch skips the network entirely — even with no signal.
